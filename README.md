# 우주 숙제검사 🪐

학생이 숙제 검사를 통과할 때마다 선생님이 웹에서 체크해요.
**정해 둔 숙제를 모두 통과하면 그 학생만의 랜덤 행성이 우주에 "뿅!" 하고 태어나요.**
반 친구들이 많이 참여할수록 우리 반 우주가 별 → 성운 → 유성 → 오로라 → 무지개 은하로 점점 화려해져요.

- 행성은 일반·희귀·영웅·전설 등급으로 랜덤하게 만들어져요 (고리, 달, 구름, 반짝이 등)
- 교실 TV에는 행성이 둥둥 떠다니는 **우주 화면**, 선생님은 번호와 이름을 보며 **체크 화면**을 써요
- 학년, 반, 학생 명단, 숙제 항목(1~6개), 비밀번호를 화면에서 직접 정해요. 코드를 몰라도 돼요
- 필요한 것은 `index.html` 파일 하나예요

---

## 어떤 방법으로 쓸까요?

| | 방법 1. 내 컴퓨터에서 바로 열기 | 방법 2. Claude 웹앱으로 게시하기 |
|---|---|---|
| 필요한 것 | 컴퓨터와 인터넷 브라우저(크롬 추천) | Claude 계정 |
| AI 종류 | **필요 없음** (ChatGPT, Gemini 등 무관) | Claude만 가능 |
| 기록이 저장되는 곳 | 그 컴퓨터의 브라우저 | Claude의 저장소 (여러 기기에서 같이 보여요) |
| 어울리는 경우 | 교실 컴퓨터 한 대를 TV에 연결해서 쓸 때 | TV는 우주 화면, 폰이나 노트북으로 체크하고 싶을 때 |

처음이시면 **방법 1**부터 해 보세요. 가장 간단해요.

---

## 방법 1. 내 컴퓨터에서 바로 열기 (AI 필요 없음)

### 1단계. 파일 내려받기
1. 이 저장소 화면에서 파일 목록의 **`index.html`**을 눌러요.
2. 파일 화면 오른쪽 위에 있는 **아래쪽 화살표 모양 아이콘**(Download raw file)을 눌러요.
3. 내려받은 파일의 이름이 **`index.html`**인지 확인해요. `index (1).html`처럼 번호가 붙어도 열리는 데는 문제없어요.

### 2단계. 파일 열기
1. 내려받은 파일을 **두 번 클릭**해요. 크롬 같은 인터넷 브라우저에서 열려요.
2. 메모장 같은 다른 프로그램으로 열리면, 파일을 마우스 오른쪽 버튼으로 눌러 **연결 프로그램 → 크롬**을 골라요.

### 3단계. 처음 설정하기
처음 열면 "처음 설정" 화면이 나와요. 다음을 입력하고 **저장**을 눌러요.
- 제목 (예: 과학 숙제 우주)
- 학년 (예: 1학년. 비워도 돼요)
- 선생님 모드 비밀번호 (화면에는 1234가 미리 적혀 있어요. 바꾸셔도 돼요)
- 숙제 항목 이름 (예: 형성평가, 교과서 문제). **＋ 항목 추가**로 최대 6개까지 만들 수 있어요
- 반 이름과 학생 명단. 한 줄에 한 명씩 `번호 이름`으로 적어요

```
1 김하늘
2 이바다
3 박구름
```

### 4단계. 사용하기
- **🧑‍🏫 선생님** 버튼 → 학생을 찾아 칸을 눌러 체크해요. 다시 누르면 취소돼요
- **🔭 우주 보기** 버튼 → 우주 화면이 나와요. 행성을 누르면 이름과 특징이 보여요
- 위쪽 탭으로 반을 바꿔요

### 교실 TV에 띄워 쓰기
컴퓨터를 TV에 연결한 다음 둘 중 편한 방법으로 하세요.
- **가장 쉬운 방법:** TV에 우주 화면을 띄워 두고, 검사할 때만 **선생님** 버튼을 눌러 체크한 뒤 다시 **우주 보기**로 돌아와요.
- **창 두 개로 쓰는 방법:** 같은 컴퓨터에서 같은 브라우저로 파일을 한 번 더 열어요. 한 창은 TV 쪽으로 끌어다 놓고 **우주 보기**, 다른 창은 **선생님**으로 체크해요. 체크하면 TV 창에 "뿅!"이 바로 나타나요.

### 꼭 알아두세요 (방법 1)
- 기록은 **그 컴퓨터의 그 브라우저**에만 저장돼요. 다른 컴퓨터나 다른 브라우저에서는 보이지 않아요.
- 브라우저의 **방문 기록·쿠키·사이트 데이터를 지우면 기록도 같이 사라질 수 있어요.**
- 그래서 가끔 **백업**을 해 두세요. 선생님 모드 → **⚙️ 설정** → **기록 백업**에서 **백업 만들기**를 누르면 글이 나와요. 그 글을 통째로 복사해 메모장에 저장해 두면 돼요. 나중에 같은 화면에서 그 글을 붙여넣고 **복원하기**를 누르면 돌아와요. 다른 컴퓨터로 옮길 때도 같은 방법이에요.

## 방법 2. Claude 웹앱으로 게시하기

여러 기기(TV, 선생님 폰, 노트북)가 **같은 기록**을 보게 하고 싶을 때 쓰세요. 이 방법은 Claude에서만 돼요. ChatGPT나 Gemini에서는 기록 저장 기능이 연결되지 않아요.

1. 위 방법 1의 **1단계**대로 `index.html`을 내려받아요.
2. Claude 대화창에 그 파일을 첨부하고, 아래 문장을 **그대로 복사해서** 보내요.

   > 이 index.html을 수정하지 말고 그대로 웹앱으로 게시해줘. 그리고 데이터 저장(db)과 사용자 확인(user) 기능을 켜줘.

3. Claude가 알려 주는 링크를 **선생님 계정으로** 열어요. "처음 설정" 화면이 나오면 방법 1의 **3단계**처럼 입력하고 저장해요.
4. 교실 TV에서는 같은 링크를 열고 **우주 보기**를, 선생님 기기에서는 같은 링크를 열고 **선생님** 모드를 써요. 체크하면 TV에 바로 반영돼요.

### 꼭 알아두세요 (방법 2)
- 체크는 **편집 권한이 있는 선생님 계정**으로 열었을 때만 저장돼요. 링크를 공유받아 보기만 하는 계정은 읽기 전용이에요.
- 공유 범위는 웹앱 페이지의 공유 메뉴에서 정해요.
- 선생님마다 웹앱이 따로 만들어져서, 다른 선생님의 기록과 섞이지 않아요.
- 계정이나 요금제에 따라 이 기능을 쓸 수 없을 수 있어요. 그럴 때는 방법 1을 쓰세요.

## 자주 묻는 질문

**선생님 모드 비밀번호는 안전한가요?**
학생이 실수로 선생님 화면을 여는 것을 막는 용도예요. 보안 장치는 아니에요.

**숙제 항목이나 명단을 바꾸고 싶어요.**
선생님 모드 → **⚙️ 설정**에서 바꿀 수 있어요. 번호가 같으면 체크 기록이 이어져요. 다만 **항목 개수를 바꾸면** 이미 쌓인 기록과 맞지 않을 수 있어서, 학기 중간에는 바꾸지 않는 것을 권해요.

**행성은 학생마다 똑같이 나오나요?**
아니에요. 학생마다 처음 완성하는 순간 랜덤으로 정해지고, 그 뒤에는 바뀌지 않아요.

**학생 이름은 어디에 저장되나요?**
선생님이 입력한 명단은 선생님의 컴퓨터(방법 1) 또는 선생님의 Claude 웹앱(방법 2)에만 저장돼요. 이 저장소에는 학생 이름이 들어 있지 않아요. 이 저장소를 고쳐서 다시 공개할 때도 **학생 이름은 올리지 마세요.**
