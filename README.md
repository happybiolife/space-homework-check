# 우주 숙제검사

학생들이 숙제 검사를 받을 때마다 선생님이 웹에서 체크하고, **모든 항목을 통과하면 그 학생만의 랜덤 행성이 우주에 "뿅!" 하고 태어나는** 교실용 웹앱이에요. 반 전체가 많이 참여할수록 우리 반 우주가 더 화려해져요.

- 선생님 화면: 번호·이름 검색, 칸을 눌러 체크(도장 소리), 취소 가능
- 우주 화면: 교실 TV에 띄워 두는 화면. 행성이 둥둥 떠다니고, 체크가 되면 "뿅!" 연출이 나와요
- 행성은 일반·희귀·영웅·전설 등급으로 랜덤 생성돼요 (고리, 달, 구름, 반짝이 등)
- 반 전체 진행률에 따라 별 → 성운 → 유성 → 오로라 → 무지개 은하로 우주가 바뀌어요
- 학년·반·학생 명단·숙제 항목(1~6개)·비밀번호를 화면에서 직접 설정해요. 코드를 고칠 필요가 없어요

## 사용 방법

이 앱은 파일 하나(`index.html`)예요. 체크 기록을 저장하려면 Claude의 웹앱(아티팩트) 기능으로 게시해야 해요.

1. 이 저장소의 `index.html`을 내려받아요.
2. Claude 대화창에 파일을 첨부하고 아래 문장을 그대로 보내요.

   > 이 index.html을 수정하지 말고 그대로 웹앱으로 게시해줘. 그리고 데이터 저장(db)과 사용자 확인(user) 기능을 켜줘.

3. 게시된 링크를 **선생님 계정으로** 열면 "처음 설정" 화면이 나와요. 제목, 학년, 숙제 항목, 반과 학생 명단, 비밀번호를 입력하고 저장해요.
4. 교실 TV에서는 같은 링크를 열고 "우주 보기"를, 선생님 기기에서는 "선생님" 모드를 사용해요.

설정은 나중에 선생님 모드의 ⚙️ 설정에서 언제든 바꿀 수 있어요.

## 알아둘 점

- **내 웹앱의 기록은 내 것만 저장돼요.** 파일을 복사해서 게시하면 선생님마다 별도의 저장소가 생겨서 다른 선생님의 기록과 섞이지 않아요.
- 체크는 **편집 권한이 있는 선생님 계정**에서만 저장돼요. 링크를 공유받아 보기만 하는 계정은 읽기 전용이에요.
- 선생님 모드 비밀번호는 학생이 실수로 선생님 화면을 여는 것을 막는 용도예요. 보안 장치는 아니에요.
- 숙제 항목 개수를 바꾸면 이미 쌓인 체크 기록과 맞지 않을 수 있어요. 학기 중간에는 바꾸지 않는 것을 권해요.
- **학생 이름은 이 저장소에 올리지 마세요.** 명단은 게시한 웹앱의 설정 화면에서만 입력해요.
